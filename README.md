# Linear_models-bayesian-nonlinear

# 📊 Linear Models, Bayesian & Nonlinear Methods

This repository contains a set of scripts, problem sets, and technical documents related to the study and implementation of **linear models**, **Bayesian inference**, and **nonlinear estimation**. The materials were developed in the context of advanced statistics coursework and modeling exercises in R.

## 📂 Repository Structure

| Folder / File | Description |
|---------------|-------------|
| `docs/`        | Final reports and assignments in PDF format. |
| `scripts/`     | R scripts covering estimation theory, linear model diagnostics, generalized inverses, estimability, and Bayesian hypothesis testing. |
| `README.md`    | Repository overview and content summary. |

## 💻 R Scripts (`/scripts`)

Includes structured scripts addressing specific theoretical and applied problems:

| Script | Focus |
|--------|-------|
| `Problema1_ZairaPerez.R` to `Problema5_ZairaPerez.R` | Solutions to model-based problem sets. |
| `Tarea1_ZairaPerez.R`, `Tarea2_ZairaPerez.R` | Script versions of homework tasks. |
| `6_Inversas_generalizadas_rango_incompleto.R` | Handling generalized inverses under rank deficiency. |
| `9_Estimacion_betas_rango_incompleto.R` | Estimation of β coefficients under incomplete rank conditions. |
| `12_Reparametrizacion_dummys_rangoincompleto.R` | Model reparameterization and dummy variables. |
| `15_Estimabilidad_contrastes.R` | Estimability of contrasts and constraints. |
| `16_Estimabilidad_teoremas.R` | Theoretical background on estimability. |
| `18_Modelobalanceado_estimabilidad.R` | Balanced models and parameter identification. |
| `pruebahipot_factorA.R`, `pruebahipot_factorB.R` | Bayesian hypothesis testing on factors A and B. |

## 🧮 Topics Covered

- Linear models and least squares
- Matrix algebra in statistics
- Estimability and identifiability
- Generalized inverse and underdetermined systems
- Hypothesis testing in fixed models
- Bayesian comparison of group means
- Reparameterization under rank constraints

All scripts are reproducible in **R** and serve both pedagogical and applied modeling purposes.
